# Спасение Яндекс Диска

Страница для скачивания файлов с Яндекс Диска на компьютер прямо из браузера — когда синхронизация не работает, а на сайте Диска файлы приходится скачивать по одному.

## Что умеет

- показывает папки Диска — можно выбрать, что скачивать;
- сохраняет файлы в выбранную папку на компьютере с той же структурой папок;
- не скачивает повторно то, что уже лежит в папке;
- если оригинал фото недоступен, сохраняет его уменьшенную копию (до 1280 px);
- видео и большие файлы, которые не скачались, пробует ещё раз; оборванное скачивание продолжает с места обрыва;
- список нескачанного записывает в `failed.csv` — при повторном запуске докачивается только недостающее.

## Безопасность

Вся работа идёт в вашем браузере: ключ доступа и файлы передаются только между Яндексом и вашим компьютером. Сервера у страницы нет, код целиком — в одном файле `index.html`.

## Требования

Google Chrome на компьютере (Windows, macOS, Linux). Другие браузеры не умеют сохранять файлы в выбранную папку.
