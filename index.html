Спасение Яндекс Диска

Скачивает файлы с вашего Диска в папку на компьютере, сохраняя структуру папок. Всё работает в вашем браузере: ключ доступа и файлы идут только между Яндексом и вашим компьютером.

Настоящий адрес страницы — только preispolnenone.github.io/yadisk-rescue. Не вводите ключ на копиях по другим адресам.

Этот браузер не умеет сохранять файлы в выбранную папку. Откройте страницу в Google Chrome на компьютере.

1. Вход

Яндекс спросит разрешение только на чтение Диска.
Вставить ключ доступа вручную

Откройте страницу Яндекса, войдите в свой аккаунт, нажмите «Получить OAuth-токен» и вставьте строку сюда. Ключ даёт доступ к вашему Диску — никому его не пересылайте.

2. Куда сохранить

Папка не выбрана

Если в папке уже лежит часть файлов Диска (например, копия папки синхронизации), они не будут скачиваться повторно.

3. Что скачать

Папки Диска — снимите галочки с ненужных:

Войдите (шаг 1) — после этого здесь появится список папок вашего Диска.

4. Если файл не скачивается

У большинства фото существует уменьшенная копия. Копия до 1280 px — хватит для просмотра, но не для печати. Если оригинал позже станет доступен, он скачается. У видео копий нет.
Куда класть копии:
Имя копии — фото (уменьшенная копия).jpg.
Видео и файлы больше 20 МБ часто не скачиваются из-за перебоев у Яндекса. Вторая попытка идёт медленнее, но вероятность скачать больше.

    
Не всё скачалось? Часть файлов на серверах Яндекса сейчас недоступна. Некоторые из них со временем снова начинают скачиваться, другие — нет, и заранее это не узнать. Можно нажать «Скачать» ещё раз через несколько часов: уже скачанное пропускается, пробуются только недостающие файлы. Их список — в файле failed.csv в выбранной папке. Не закрывайте вкладку, пока идёт скачивание.
